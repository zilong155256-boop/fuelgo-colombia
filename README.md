# FuelGo Colombia — visual-only handoff
This is a **static presentation site** for deployment by a developer.

Files included:
- index.html — page layout and five-image, horizontally swipeable phone gallery
- fuelgo-logo.svg — site logo
- assets/*.png — five user-supplied phone screenshots

Tracking and APK download behavior have been removed. CTA and share controls are visually displayed only and **do not perform any action**. No Meta Pixel, conversion events, metrics, cookies, download worker, or download/API functions are included.

To deploy: publish this branch root as a static website (no build command and no server-side functions). The large hero banner background is referenced from Wikimedia Commons; for completely offline use, download a properly licensed copy and update the CSS URL while preserving attribution.

This is a developer handoff branch; do not confuse it with the live main branch. Review the page's public marketing claims before production deployment.
